# Reminder For You

A simple reminder application built as a Progressive Web App (PWA) that can be installed on Windows and used offline.

## Features

- Add, complete, and delete reminders
- Filter reminders by status (all, active, completed)
- Works completely offline
- Local storage for data persistence
- Installable on desktop through Windows PWA support

## Installation

1. Install dependencies
```
npm install
```

2. Start the development server
```
npm start
```

3. Build for production
```
npm run build
```

4. Serve the production build
```
npm run serve
```

## Installing as a PWA

1. Open the app in a compatible browser (Chrome, Edge)
2. Look for the install icon in the address bar
3. Click "Install" to add the app to your desktop
4. The app will now be available in your Start menu and can be used offline

## Usage

- Add a new reminder by typing in the input field and clicking "Add"
- Mark reminders as complete by clicking the checkbox
- Delete reminders with the "Delete" button
- Filter reminders using the "All", "Active", and "Completed" buttons
- The app works offline and your reminders are always available
